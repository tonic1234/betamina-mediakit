FAQ

Perguntas Frequentes

O que é a Betamina e qual é sua identidade visual?
A Betamina é uma plataforma multisport e cassino voltada ao jogador LATAM. Sua identidade é construída sobre um conceito energético: linhas dinâmicas, diagonais agressivas, azuis vibrantes e tipografia geométrica — tudo projetado para transmitir impulso, velocidade e diversão.
O que inclui cada pack do Mediakit?
Cada seção é baixada como um ZIP independente com todos os arquivos prontos para produção:

Logotipos → logos, favicon e isotipos oficiais em SVG, PNG e PDF
Paleta de Cores → brand book com tokens CSS e JSON
Tipografia → FT Calhern Wide (display) em WOFF2 e OTF
Broadcast Assets → layouts, overlays e animações para streamers em MOGRT, PNG seq e AE
Set de Ícones → 27 ícones oficiais em formato SVG
Guia de Marca → manual de marca oficial em PDF e Markdown
Qual é a tipografia oficial?
A tipografia institucional é FT Calhern, uma sans serif geométrica contemporânea. Recomenda-se usá-la exclusivamente em todas as comunicações oficiais para manter a coerência do sistema visual.
Quais são as cores oficiais?
A paleta principal é composta por três azuis e dois neutros:

Primary Blue #0068F9 — Pantone 2727 C
Secondary Blue #0048C5 — Pantone 293 C
Tertiary Blue #0039AC — Pantone 294 C
White #FFFFFF e Light Gray #E2E2E2 — Cool Gray 1 C
Existe uma área de proteção para o logo?
Sim. O logo requer uma área livre definida pelo módulo X (distância entre a base de "BETAMINA" e a borda inferior do contêiner), aplicada aos quatro lados. Nenhum elemento gráfico deve invadir essa zona.
Posso usar esses assets em projetos de clientes ou produção própria?
Os recursos são otimizados para produção profissional — agências, designers e desenvolvedores que trabalham com a marca. Todos os formatos são vetoriais ou de alta resolução, prontos para implementar sem ajustes adicionais.
Preciso me registrar para baixar?
Não. O download é gratuito e sem necessidade de registro. Cada pack está disponível como ZIP individual ou você pode baixar o Mediakit completo (126 MB) na seção de download.
